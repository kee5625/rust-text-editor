Hello, hecto!
==============

This is a test file for the hecto text editor.
Try scrolling around using the arrow keys!

-- Basic Movement --
  Arrow Up    : move cursor up
  Arrow Down  : move cursor down
  Arrow Left  : move cursor left
  Arrow Right : move cursor right
  Home        : jump to start of line
  End         : jump to end of line
  Page Up     : jump to top of screen
  Page Down   : jump to bottom of screen
  Ctrl+Q      : quit the editor

Rows of tildes line the screen,
Where no text has ever been.
A cursor blinks, awaiting thought,
